# RugbyKit

RugbyKit is a player simulation prototype 


- Player profile with core rugby attributes
- Training drills that change stats, fatigue and confidence
- Match phase simulation with random rugby events
- Pitch state, form timeline and selection status
- Polished React/Vite interface with no API keys required

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
